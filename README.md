## 📦 What's Inside

A practical toolkit of reusable, responsive UI components and lightweight boilerplates designed for students and developers building modern web projects.

### 🌟 Templates
- `starters/html5-starter/`: Production-ready baseline HTML5 template with SEO meta tags, responsive viewport configuration, and CSS reset.
- `starters/landing-starter/`: Modern, dark-themed hero landing page template.

### 🎨 Components
- Reusable CSS Button variants (Primary, Secondary, Success, Danger)
- Responsive content and feature cards
- Clean container systems
